Icorender Documentation

Welcome to the official Icorender wiki. This guide covers project architecture, command-line interface usage, and feature overview. This wiki is for the latest version. (1.0.2)

What is Icorender?

Icorender is a command-line interface tool designed to package and append icon files (.ico) directly into a binary library (project.dll). It provides built-in backup management and external script execution capabilities.

Getting Started

Export the DLL:

python compiler.py

View tools:

python tools.py
